# Dither background editions

Created using the built-in image generation tool. Each matching file in ../sanova-gradients/ was supplied as the edit target, with the user-provided green halftone screenshot as the texture reference. Original assets are preserved.

## Prompt used for all nine edits

Edit Image 1, the target background. Image 2 is a TEXTURE STYLE REFERENCE ONLY. Preserve Image 1's exact abstract shapes, color palette, light and dark placements, flowing contours, crop and aspect ratio. Transfer ONLY the distinctive visible ordered dither / halftone dot treatment from Image 2: fine crisp regularly spaced screen dots, changing density and size across tonal transitions, light dots in dark areas and dark dots in lighter regions, rich soft continuous underlying tones. Match the reference's intentional graphic print texture, not random photographic grain or a generic uniform polka-dot overlay. Dither must be clearly visible at normal viewing scale and integrated into existing curves, preserving calmer solid areas. Replace the existing noisy grain with this controlled dotted texture. Do not copy Image 2's composition, diagonal bands or green palette into Image 1. In particular, ivory/gray target images must remain ivory/gray. No new objects, logos, symbols, typography, borders or mockups. Output one edited background only.
